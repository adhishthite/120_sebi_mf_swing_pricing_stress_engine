# SEBI Mutual Fund Swing Pricing & Stress Engine: Frontend Architecture

The frontend is an enterprise risk surveillance cockpit built with Next.js 16, React 19, Tailwind CSS v4, shadcn/ui primitives, and self-hosted IBM Plex typography. Managed exclusively via `pnpm`.

---

## 1. Design Read & Google Design System Selection

```
Reading this as: B2B regulatory debt compliance workspace for fund risk managers, with a serious, technical, and high-density visual language, leaning toward Cloud Design System (CDS / Pantheon) archetype with IBM Plex Sans/Mono typography.
```

- **Archetype**: Cloud Design System (CDS / Carbon / Pantheon).
- **Typography**: `@fontsource/ibm-plex-sans` for UI controls and labels; `@fontsource/ibm-plex-mono` for numeric parameters, calculation tables, and audit logs. Zero external font CDNs.
- **Icons**: `@phosphor-icons/react` for high-clarity technical glyphs.
- **Color System**: OKLCH semantic palette with high-contrast warning indicators for SEBI market dislocations and swing factor triggers.

### Visual Dials
- **`DESIGN_VARIANCE: 4`**: Predictable 4px grid, clear structural boundaries, zero AI-purple gradients or floating elements.
- **`MOTION_INTENSITY: 2`**: Restrained state transitions with instant feedback on scenario switches.
- **`VISUAL_DENSITY: 8`**: Compact information hierarchy, dense metrics cards, and monospaced calculation tables.

---

## 2. 2-Step Onboarding & Split-Screen Workflow

- **Step 1 (Scheme Configuration)**:
  - Configure Scheme Category, AUM (INR), Potential Risk Class (PRC A-I to C-III), Market Dislocation switch, and Discretionary Outflow Threshold.
- **Step 2 (Split-Screen Workspace)**:
  - **Left Pane**: Scenario Presets (`SCEN-A` to `SCEN-SAFE`), investor simulation parameters, and PII sandbox testing panel.
  - **Right Pane**: 4-Step Storyboard Walkthrough:
    1. **Data Protection (PII Masking)**: Comparative JSON viewer displaying gateway masking of Aadhaar/PAN.
    2. **Statutory Guardrails**: Real-time evaluation of `pii_protection.cel`, `portfolio_compliance.cel`, and `swing_pricing_triggers.cel` with interactive code view.
    3. **Stress Liquidation & Swing Calculation**: Waterfall steps, bid-ask spread costs, Kyle's lambda market impact, and adjusted NAV.
    4. **Multi-Agent Synthesis**: Natural language regulatory commentary generated by Gemini 3.5.
  - **Visualizations**: Interactive Recharts displaying pre- vs post-stress portfolio composition and liquidation cost breakdown.
  - **Live Audit Feed**: Real-time append-only telemetry terminal tracking latency, token metrics, and compliance decisions.

## 3. Development Commands (pnpm Only)

```bash
# Install dependencies
pnpm install

# Run development server (bound to port 3120)
pnpm dev

# Build production bundle
pnpm build

# Start production server
pnpm start

# Format and Lint check
pnpm biome check src/
```
